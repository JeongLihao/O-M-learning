### 端口/链路聚合

#### 一、原理

+ 把交换机的多个物理端口捆绑合成一个逻辑端口，在交换机之间形成一条拥有较大宽带的链路，还可以实现负载均衡，并提供冗余链路

#### 二、作用

+ 提高链路带宽
+ 支持负载均衡
+ 提供链路备份
+ 防止网络环路

#### 三、要求

+ 在一个端口汇聚组中，端口号最小的作为主端口，其他的为成员端口
+ 聚合端口的特性必须一致（接口速率、双工模式、链路类型等）
+ 端口号必须连续，一个汇聚组最多可以有8个端口
+ 聚合成一个独立的逻辑端口后，不能再对成员端口单独配置，且不能开启端口安全功能

#### 四、相关命令

```
//实现步骤
//1.将端口配置为Trunk模式
inter range f0/23-24
switch mode trunk
//2.加入链路组1并开启
channer-group 1 mode on
//3.实现负载均衡（如目的IP）
port-channer load-balance dst-ip

//查看与配置命令
//1.显示以太通道信息
show etherchanner summary
//2.显示聚合端口信息
show interfaces etherchannel
//3.进入聚合端口的端口配置模式
interface port-channel 1
```
