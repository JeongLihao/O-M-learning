### 三层交换机

#### 一、使用

```
//1.在全局配置模式中开启路由功能
	ip routing
//2.对接口进行转换
	no switchport
//2.配置接口
	interface f0/1
	ip address XXX.XXX.XXX XXX.XXX.XXX
	no shutdown
	interface vlan 20
	ip address XXX.XXX.XXX XXX.XXX.XXX
	no shutdown
//3.保存配置
	end
	write memory
```

#### 二、配置中继模式

```
1.switchport trunk encapsulation dot1q
2.switchport mode trunk 
```

#### 三、查看配置

```
1.查看路由表信息
show ip routing 
2.查看所有接口的简要信息
show interfaces britf
3.查看单个接口的详细信息
show interfaces GigabitEthernet 0/1
4.查看接口的IP地址配置信息
show interfaces GigabitEthernet 0/1 ip
5.查看接口的 VLAN 和中继信息
show interfaces GigabitEthernet 0/1 switchport
show running-config
7.查看当前正在运行的配置信息。
show vlan brief
8.查看 VLAN 的简要信息，包括 VLAN ID、名称和端口分配情况。
show interfaces trunk
9.查看 Trunk 接口的相关信息。
```
