### 单臂路由

#### 一、原理

1. 单臂路由是指在路由器的一个接口上通过配置子接口的方式，以作为VLAN的网关，实现原来相互隔离的不同VLAN之间的互联互通
2. VLAN间互访的原理：在接入路由器的一个物理端口上启用多个子接口，每一个子接口与各个Vlan一一对应充当其网关，通过直连路由实现VLAN间相互访问
3. 与三层交换的方式相比，其通过软件实现交换，转发效率没有三层交换机高，随着网络拓扑增大，容易出现性能瓶颈，不适用于中、大型局域网

+ dot1q 封装协议：即IEEE 802.1Q 标准，是为防止中继端口上承载的不同VLAN相互混乱而设计的一种VLAN封装方式，其定义了 VLAN网桥操作，从而允许在桥接局域网结构中实现定义、运行以及管理 VLAN 拓朴结构等操作

#### 二、步骤

1. **交换机配置**

````
//1. 创建VLAN1和VLAN2
	vlan 1
	exit
	vlan 2
	exit
//2. 设置端口模式为为Access(连接终端的端口)
	switchport access vlan 1
//3. 设置端口模式为Trunk(连接路由器的端口)
	switchport mode trunk
//4. 查看VLAN配置信息
	show vlan 
````

2. **路由器配置**

```
//1. 开启端口
	no shutdown
//2. 进入子接口
	inter f0/0.1
//3. 封装协议
	encapsulation dot1Q 2
//4. 设置网关IP
	ip address 192.168.10.254 255.255.255.0
//5. 查看路由表信息
	show ip route
```
