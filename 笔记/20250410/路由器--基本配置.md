### 路由器基本配置

#### 一、路由器的基本介绍

+ 接口丰富，数量少
+ 默认接口关闭，需要手动开启

#### 二、Telnet连接

```
//1. 进入端口模式
	inter g0/0
//2. 配置路由器的端口IP
	ip address 192.168.10.254 255.255.255.0
//3. 开启端口并退出端口模式
	no shutdown
	exit
//4. 进入线路配置模式
	line vty 0 4
//5. 设置密码并退出
	password XXX
	exit
//6. 启用全局密码加密功能
	service password-encryption
//7. 设置特权模式密码
	enable password XXX
//8. 保存
	write
```

#### 三、SSH连接

```
//1. 配置设备名称
	hostname XXX
//2. 配置设备域名
	ip domain-name XXX.com
//3. 生成密钥对
	crypto key generate rsa
//4. 启用SSH版本，设置本地用户登录以及设置本地用户和密码
	username XXX password XXX (设置用户名和用户密码)
	enable password XXX (设置特权模式密码)
	ip ssh version 2 (启用SSH版本)
//5. 选择端口并配置IP地址
	interface g0/0 (选择端口)
	ip address XXX XXX (绑定IP)
	no shutdown (启用端口)
	exit (返回上一级)
//6. 开启虚拟线路并允许本地账户登录
	line vty 0 4 (设置虚拟线路)
	transport input ssh (用于指定SSH协议来访问终端)
	login local (允许本地账户登录)
```

#### 四、多网络互联

```
//1. 进入端口模式
	interface g0/0
//2. 配置IP以及开启端口
	ip address XXX XXX
	no shutdown

	show ip route
//4. 保存配置

```
