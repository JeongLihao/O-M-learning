### 交换机的配置

#### 一、模式

+ 基本模式主要包括用户模式、特权模式和全局配置模式

1. 用户模式

   + 进入方式：连接交换机后回车

   + 提示符：主机名>（通常为Switch>）
   + 退出方式：输入`exit`或`logout`

2. 特权模式

   + 进入方式：在用户模式中输入`enable`
   + 提示符：主机名#（通常为Switch#）
   + 功能用途
     1. 查看详细设备信息与配置
     2. 执行高级命令
     3. 进入其他配置模式

   + 退出方式：`disable`返回用户模式，`exit`退回初始状态

3. 全局配置模式

   + 进入方式：特权模式下输入`configure terminal`
   + 提示符：主机名(config)#（通常为Switch(config)）
   + 功能用途
     1. 配置交换机的全局参数
     2. 进入其他子配置选项

   + 退出方式：`exit`或`ctrl+z`返回特权模式

4. 端口模式
   + 进入方式：特权模式下输入`interface 端口类型 0/1`
   + 提示符：主机名(config-if)#（通常为Switch(config-if)#）

5. VLAN模式
   + 进入方式：特权模式下输入`vlan 编号`
   + 提示符‌： 主机名(config-vlan)#（通常为Switch(config-vlan)#）‌

#### 二、技巧

1. 命令语法：关键字 参数
2. 简写：如enble可以简写为en
3. 可以使用tab补全
4. 使用?查看清单与关键字
5. ctrl+c中断正在运行的过程
6. ctrl+shift+6中断域名解释
7. 通过方向上下，滚动查看历史命令

#### 三、操作命令

1. 用户模式
   + `show version`：显示设备版本信息
   + `show users`：显示当前登录用户
   + `enable`：进入特权模式
   + `exit or logout`：退出
2. 特权模式
   + `show running-config`：查看当前配置清单
   + `show mac-address-table`：查看MAC地址表
3. 全局模式
   + `hostname`：修改主机名
4. 端口模式
   + `shutdown`：关闭端口
   + `no shutdown`：开启端口
   + `speed 10 or auto`：设置带宽为10或设置为自动
   + `duplex half or full or auto`：设置为全双工或半双工或自动
5. 关键命令
   + `enable or disable`：进入或退出特权模式
   + `write`：保存当前运行配置
   + `reload`：重启设备
   + `show`：查看设备运行状态等

#### 一、怎么给console连接设置密码

1. **进入全局配置模式**

   先输入`enable`进入特权模式，再输入`configure terminal`进入全局配置模式

2. **设置console端口密码**

   1. Switch(config)# line console 0
   2. Switch(config-line)# password pwd
   3. Switch(config-line)# login

   + pwd是要设置的密码
   + login表示开启登录认证

3. **保存配置**

   返回特权模式，使用`write memory`保存配置

#### 三、交换机进行VLAN划分

1. **进入全局配置模式**

​		先输入`enable`进入特权模式，再输入`configure terminal`进入全局配置模式

2. **创建VLAN**
   1. Switch(config)# vlan 10
   2. Switch(config-vlan)# name XXX
   3. Switch(config-vlan)# exit

3. **将端口分配到VLAN**
   1. 先进入端口配置模式----如`interface FastEthernet 0/1`
   2. 将交换机端口设置为接入模式`switchport mode access`
   3. 将端口分配到相应的VLAN----如`swichport access vlan 10`
   4. 返回`exit`

4. **保存配置**

​		返回特权模式，使用`write memory`保存配置
