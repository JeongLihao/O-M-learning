

### 一、如何设置Console密码

1. **流程**

```
1. enable + configure terminal	//进入全局配置模式
2. line console 0				//控制台线路模式
3. password XXX					//设置控制台登录密码
4. login						//启用密码验证
5. end							//退出所有配置模式
6. show running-config			//显示配置文件内容
7. write						//保存配置
```

2. **对密码进行加密**

   + 密码默认以明文形式存储于配置文件中

   + 启用全局密码加密服务

     ```
     service password-encryption		//对明文密码进行弱加密
     ```

### 二、如何进行Telnet配置

1. **流程**

   ```
   1. 进入全局模式 
   2. line vty 0 4						//进入虚拟终端线路配置
   3. password XXX						//设置Telnet登录密码
   4. login							//启用密码验证
   5. transport input telnet			//指定线路接受Telnet连接
   6. 退出当前配置模式
   7. interface vlan 1					//进入端口配置模式
   8. ip address XXX XXX				//给交换机设置ip和子网掩码
   9. no shutdown						//激活该虚拟端口
   ```

   

2. **对特权模式进行密码配置**

   1. 查看配置

      `show running-config | include enable`

   2. 设置明文密码

      `enable password XXX`

   3. 设置加密密码

      `enable secret XXX`

### 三、如何进行SSH配置

1. **流程**

   ```
   1. 设置ip
   2. 设置特权模式密码
   3. hostname XXX						//修改主机名
   4. ip domain-name XXX				//生成域名
   5. crypto key generate rsa			//生成RSA密钥
   6. username XXX secret XXX			//创建本地用户和密码
   7. line vty 0 4 					//进入虚拟终端线路配置
   8. transport input ssh				//只允许SSH登录
   9. login local 						//使用本地用户验证
   10. show ip ssh						//确认启用
   ```

   

2. **连接**

   + 真机

     `ssh admin@192.168.10.1`

   + 模拟器

     `ssh -l admin 192.168.10.1`

3. **关键命令**

   + 保存配置

     `write`

   + 查看ssh状态

     `show ip ssh`

   + 查看配置清单

     `show run | include`

### 四、取消登录方式

1. 取消 Telnet 登录方式，进入全局配置模式

   `no line vty 0 4`

2. 取消 SSH 登录方式，全局配置模式下

   + `no ip ssh version 2`

   + `no crypto key generate rsa` 

   关闭 SSH 服务并删除相关密钥
