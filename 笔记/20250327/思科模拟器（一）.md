### 软件基础

#### 1、接口分类

+ Ethernet以太网接口
  + E代表10M网卡接口，如`E0/1`
  + 其中的0为模块号，1为接口号，也就是10M网中的0号模块中的1号接口
+ FastEthernet：100M接口
+ F0/1 ：F代表100M网口
+ GigabitEthernet：1000M接口
+ G0/1：G代表1000M网口  、T 则是10000M

#### 2、线型分类

+ 同类用交叉线（虚线）
+ 异类用真通线（实线）

#### 3、端口状态灯

+ 红色：未连接
+ 橙色：协商中
+ 绿色：正常

#### 4、标准C类网

`192.168.10.0---192.168.10.255`

### 其他

1. **为什么交换机不用设置IP**
   - 工作原理：二层交换机工作在数据链路层，主要功能是根据 MAC 地址转发数据帧。它通过学习连接到各个端口的设备的 MAC 地址，建立 MAC 地址表，然后依据目的 MAC 地址将数据帧从相应的端口转发出去，整个过程不需要 IP 地址参与
   - 网络拓扑构建：二层交换机用于构建本地网络，将多个设备连接在一起形成一个局域网。在局域网内，设备之间的通信基于 MAC 地址进行，交换机只负责在不同端口之间转发数据帧，以实现设备之间的互联互通，无需 IP 地址来确定数据的转发路径
   - 即插即用特性：二层交换机通常具有即插即用的特性，只要将设备连接到交换机的端口，交换机就能够自动识别并开始转发数据。这种特性使得交换机在小型局域网中部署非常方便，无需进行复杂的 IP 地址配置，降低了网络部署的难度和成本

2. **如果子网掩码改为`255.255.0.0`，PC能否通信**
   + 同一网段内的可以通信，不同网段内的在没有路由器等三层设备进行路由转发的情况下不能通信

3. **交换机的几种设置模式如用户模式、特权模式等模式下用户的权限是什么**

   1. 用户模式

      - 权限概述：这是进入交换机后默认的初始模式，用户在此模式下的操作权限非常有限，仅能对交换机的基本信息进行查看，无法对交换机的配置进行修改
      - 可执行操作示例：
          - 查看交换机的系统信息，像设备的型号、运行时间等
          - 查看当前的连接状态，例如哪些端口处于连接状态
   
    2. 特权模式
   
        - 权限概述：用户可以从用户模式通过输入特定命令（如 `enable`）进入特权模式。此模式下权限有所提升，用户能够执行一些高级的查看命令，也可以对交换机进行一些有限的管理操作，但仍然不能直接修改交换机的配置
   
        - 可执行操作示例：
            - 查看交换机的配置文件，了解当前的配置情况
            - 进行文件管理操作，如保存或备份配置文件
            - 执行一些测试命令，以检测网络的连通性等
   
        3. 全局配置模式
   
           - 权限概述：从特权模式输入 `configure terminal` 命令可进入全局配置模式。在该模式下，用户可以对交换机的全局参数进行配置，这些配置会影响到整个交换机的运行
   
   
           - 可执行操作示例：
               - 设置交换机的主机名，方便在网络中识别
               - 配置域名、时间等全局参数
               - 开启或关闭某些全局功能，如生成树协议等
   
        5. 接口配置模式
   
           - 权限概述：用户可以从全局配置模式进入接口配置模式，命令格式通常为 `interface <接口类型和编号>`。此模式下，用户可以对交换机的特定接口进行详细配置
   
   
           - 可执行操作示例：
               - 设置接口的带宽、速率等参数
               - 配置接口的工作模式，如全双工、半双工等
               - 为接口分配IP地址（如果是三层交换机）
   
        6. VLAN配置模式
   
           - 权限概述：在全局配置模式下，使用 `vlan <VLAN编号>` 命令进入VLAN配置模式。该模式用于对虚拟局域网（VLAN）进行配置和管理
   
   
           - 可执行操作示例：
               - 创建或删除VLAN
               - 为VLAN命名，方便识别和管理
               - 配置VLAN的相关参数，如VLAN的接口成员等
