### 交换机端口安全

#### 一、技术原理

+ 端口安全：交换机可根据MAC地址对网络流量进行控制和管理
+ 要保证交换机端口安全功能的正常工作，必须先将端口模式修改为接入Access端口或中继Trunk端口
+ 安全地址表项配置
  + 动态MAC地址：交换机主动学习，当端口状态改变将重新学习并更新MAC地址表
  + 静态MAC地址：人为将端口与MAC地址进行绑定，该端口不再主动学习
  + 粘性MAC地址：交换机首次主动学习MAC地址并绑定，当端口状态改变时，该端口不再主动学习

+ 当端口接收到未经允许的MAC地址流量时，交换机会执行以下违规动作：

  - 保护(Protect)：丢弃未允许的MAC地址流量，但不会创建日志消息。


  - 限制(Restrict)：丢弃未允许的MAC地址流量，创建日志消息并发送SNMP Trap消息


  - 关闭(Shutdown)：默认选项，将端口置于err-disabled状态，创建日志消息并发送SNMP Trap消息。若要重新开启该端口，需要"先关闭再打开"端口或使用errdisable recovery命令。后者在模拟器上无法使用

#### 二、案例一：限制接入的主机数

```
//1.选择要设置的端口
interface f0/24
//2.修改端口模式
switchport mode trunk
//3.开启端口安全模式
switchport port-security
//4.限制数量
switchport port-security maximum 1
//5.设置违规处理方式
switchport port-security violation shutdown
```

#### 三、案例二：将端口与MAC地址进行绑定（手动或粘性）

```
//1.选择要设置的端口
interface f0/15
//2.修改端口模式
switchport mode access
//3.开启端口安全模式
switchport port-security
//4.手动绑定MAC地址
switchport port-security mac-address XXX.XXX.XXX
//5.自动学习（粘性）
switchport port-security mac-address sticky
//6.设置违规处理方式
swichport port-security violation shutdown
```
