### 常用命令

#### 一、基础连通性测试

1. `ping`：测试与目标主机的连通性
2. `tracert`：追踪数据包到达目标主机的路径（显示经过的路由节点）
3. `pathping`：统计路径中每个节点的丢包率和延迟

#### 二、网络配置查看

1. `ipconfig`：查看本机IP地址等信息
2. `getmac`：查看本机MAC地址

#### 三、DNS查询

1. `nslookup`：查询DNS记录

#### 四、网络连接与端口分析

1. `netstat`：显示活动的网络连接、监听端口等信息
2. `telnet`：测试远程主机的端口是否开放

#### 五、路由与ARP

1. `route`：查看或修改本机路由表
2. `arp`：查看或修改ARP缓存表

#### 六、远程连接与文件传输

1. `ssh`：登录远程主机
2. `scp`：传输文件

#### 七、其他

1. `curl`：发送HTTP请求或下载文件
2. `whois`：查询域名注册信息（需安装或通过WSL）
3. `hostname`：显示本机的主机名

### 特殊IP

#### 本地网络地址

+ 0.0.0.0
  - 用途：  

    - 表示“默认路由”（所有未知目标网络的出口）  
    - DHCP发现阶段客户端初始地址  


+ 255.255.255.255

  - 用途：受限广播地址（Limited Broadcast）  
    - 仅在当前局域网内广播，不跨路由器  
    - 典型应用：DHCP客户端首次获取IP时发送请求  

  - 抓包特征：目标MAC为`FF:FF:FF:FF:FF:FF`


#### 回环地址（Loopback）

+ 127.0.0.0/8 

  - 用途：
    - 测试本地协议栈（如`ping 127.0.0.1`验证TCP/IP是否正常）  
    - 服务监听（如本地Web服务器绑定`127.0.0.1:80`）  

  - 关键特性：  
    - 数据包不离开主机，不占用物理网络带宽  
    - 路由器/交换机常用`127.0.0.1`作为管理平面地址  


+ ::1（IPv6回环）
  - 等效于IPv4的127.0.0.1  


#### 广播地址（Broadcast）

+ 直接广播（Directed Broadcast）

  - 格式：`<网络号>.255.255.255`（如`192.168.1.255`）  

  - 用途：向特定子网内所有设备发送数据包  

  - 企业级注意：  
    - 默认被路由器禁用（需通过`ip directed-broadcast`命令开启）  
    - 可能被用于DoS攻击（如Smurf攻击）  


#### 组播地址（Multicast）

+ 224.0.0.0 ~ 239.255.255.255

  - 关键地址举例：  

    | 地址        | 用途                                    |
    | ----------- | --------------------------------------- |
    | 224.0.0.1   | 所有组播主机（如OSPF的`AllSPFRouters`） |
    | 224.0.0.2   | 所有组播路由器（如VRRP）                |
    | 224.0.0.5   | OSPF协议专用                            |
    | 224.0.0.251 | mDNS（如Apple设备发现服务）             |


+ IPv6组播（FF00::/8）
  - 示例：`FF02::1`（本地链路所有节点）、`FF02::5`（OSPFv3）  


#### 保留地址（RFC 1918）

- 私有地址范围：  内网

  ```markdown
  10.0.0.0/8        → 大型企业内网  
  172.16.0.0/12     → 中型网络（如分支机构）  
  192.168.0.0/16    → 家庭/小型办公室  
  ```

- NAT转换必备：这些地址在互联网上不可路由

### 应用层主要协议

| 协议           | 用途                     | 传输层协议 |
| -------------- | ------------------------ | ---------- |
| **HTTP/HTTPS** | 网页传输（明文/加密）    | TCP        |
| **FTP** 早期的 | 文件传输                 | TCP        |
| **SMTP**       | 电子邮件发送             | TCP        |
| **POP3/IMAP**  | 电子邮件接收             | TCP        |
| **DNS**        | 域名解析（域名 ↔ IP）    | UDP/TCP    |
| **DHCP**       | 动态分配 IP 地址         | UDP        |
| **SSH**        | 安全远程登录             | TCP        |
| **REST API**   | 基于 HTTP 的应用程序接口 | TCP        |

### 传输层主要协议

| 协议    | 特点                                                         | 适用场景              |
| ------- | ------------------------------------------------------------ | --------------------- |
| **TCP** | - 面向连接（三次握手）<br>- 可靠传输（确认、重传）<br>- 流量控制（滑动窗口）<br>- 拥塞控制（慢启动、拥塞避免） |                       |
| **UDP** | - 无连接<br>- 不可靠但高效<br>- 无流量/拥塞控制              | 实时音视频、DNS、游戏 |

### 总结

| **层次** | **名称**               | **协议**                               | **设备**                   | **数据格式**       | **解决的问题**                                               |
| -------- | ---------------------- | -------------------------------------- | -------------------------- | ------------------ | ------------------------------------------------------------ |
| **7**    | 应用层 (Application)   | HTTP/HTTPS, FTP, DNS, SMTP, DHCP, SNMP | 终端设备（PC/手机/服务器） | 应用数据（如JSON） | 提供用户接口，解决应用程序间的数据交互（如网页浏览、邮件发送）。 |
| **6**    | 表示层 (Presentation)  | SSL/TLS, JPEG, MPEG, ASCII。txt        | 网关、编解码器             | 加密/压缩数据      | 数据格式转换、加密解密，解决不同系统间的数据兼容性问题。     |
| **5**    | 会话层 (Session)       | NetBIOS, RPC, SIP                      | 会话管理器                 | 会话控制信息       | 建立、管理和终止会话，解决进程间持续通信问题（如视频会议连接维护）。 |
| **4**    | 传输层 (Transport)     | TCP, UDP, SCTP                         | 防火墙、负载均衡器         | 段 (Segment)       | 端到端可靠传输（TCP）或高效传输（UDP），解决数据分段、流量控制和错误恢复问题。 |
| **3**    | 网络层 (Network)       | IP, ICMP, OSPF, BGP, ARP               | 路由器、三层交换机         | 数据包 (Packet)    | 路由选择、逻辑寻址，解决跨网络的数据转发问题（如IP寻址和路由优化）。 |
| **2**    | 数据链路层 (Data Link) | Ethernet, PPP, VLAN, STP, MAC          | 交换机、网桥、网卡         | 帧 (Frame)         | 物理寻址（MAC）、错误检测，解决局域网内设备间直接通信问题（如冲突域管理）。 |
| **1**    | 物理层 (Physical)      | IEEE 802.3 (Ethernet), USB, DSL, 光纤  | 集线器、中继器、调制解调器 | 比特流 (Bits)      | 传输原始比特流，解决信号编码、物理介质连接问题（如电缆类型、电压标准）。 |
