### 计算机网络的定义、组成

1. **定义**

   多台计算机通过某种方式连接在一起、能够互相通信和共享资源

2. **组成**

   + 硬件

     1. 主机（Host）：提供服务的计算机设备
     2. 网络设备
        + 路由器（Router）：连接不同网络，负责数据报的路由和转发
        + 交换机（Switch）：局域网内连接多台设备，负责数据帧的转发
        + 网卡（NIC）：计算机与网络之间的接口，负责数据的发送和接收

        3. 传输介质

           + 有线介质：双绞线、光纤

           + 无线介质：无线电、红外

   + 软件：协议、操作系统、网络应用程序等

*********

### 通信链路（Communication Link）

+ 定义：连接两个或多个网络设备的物理或逻辑通道，用来传输数据

+ 分类
  + 物理链路（通过物理介质传输数据）：网线、光纤、无线电等
  + 逻辑链路（通过协议或软件定义的虚拟通道）：VPN（虚拟专用网络）等

*********

### 结点（Node）

+ 定义：网络中能够发送、接收或转发数据的设备或点

+ 分类
  1. 终端结点（End Node）：直接为用户提供服务的设备，通常不参与数据转发
  2. 中间结点（Intermediate Node）：网络中负责数据转发和路由的设备，不直接为用户提供服务

+ 功能
  1. 数据发送和接收
  2. 数据转发
  3. 网络管理

### 网络协议和标准

+ （TCP\IP协议族，OSI参考模型）

+ 应用层--表示层--会话层--传输层--网络层--数据链路层--物理层

******

### OSI七层模型

#### 应用层（Application Layer）

+ 为用户提供网络服务

#### 表示层（Presentation Layer）

+ 数据格式化、加密、压缩等，确保数据能被接收方正确理解

#### 会话层（Session Layer）

+ 建立、管理和终止会话

#### 传输层（Transport Layer）

+  提供端到端的可靠数据传输

#### 网络层（Network Layer）

+ 数据包的路由和转发

#### 数据链路层（Data Link Layer）

+ 在直接相连的设备之间传输数据帧

#### 物理层（Physical Layer）

+ 将数据转换为物理信号并通过介质传输
