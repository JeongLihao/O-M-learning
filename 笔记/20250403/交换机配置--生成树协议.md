### 生成树协议

+  作用：解决环路线路
+ 最小生成树：从众多路线中找到最短路线

1. 生成树算法（STP）：慢
2. 快速生成树协议（RSTP）：在网络结构发生变化时，能更快的收敛网络

### 配置方法

+ 查看交换机生成树协议配置

  ```
  //看配置
  show spanning-tree summary
  //看状态
  show spanning-tree
  ```

+ 指定生成树协议的类型

  ```
  //指定生成树协议的类型为RSTP
  spanning-tree mode rapid-pvst
  ```
